   Make sure to check "Add Python to PATH"

2. OPEN TERMINAL/COMMAND PROMPT
   Windows: Win + R → type: cmd
   macOS: Cmd + Space → type: terminal
   Linux: Ctrl + Alt + T

3. NAVIGATE TO PROJECT
   cd C:\Users\lenovo\Desktop\voice\ assistance
   (Note: Use quotes around path with spaces)

4. CREATE VIRTUAL ENVIRONMENT
   Windows:
   python -m venv venv
   venv\Scripts\activate

   macOS/Linux:
   python3 -m venv venv
   source venv/bin/activate

   ✓ Your prompt should show (venv)

5. INSTALL REQUIREMENTS
   pip install -r requirements.txt
   (Wait 2-3 minutes for installation)

6. RUN THE APPLICATION
   
   Option A - Interactive (type commands):
   python main.py
   
   Option B - GUI (graphical):
   python main.py --gui
   
   Option C - Voice (speak):
   python main.py --voice

⚙️ OPTIONAL CONFIGURATION
================================================================================

To enable email sending:
1. Go to https://myaccount.google.com/apppasswords
2. Generate app password
3. Edit config.py:
   EMAIL_ADDRESS = "your-email@gmail.com"
   EMAIL_PASSWORD = "generated-password"
   ENABLE_EMAIL = True

To set weather location:
1. Edit config.py:
   DEFAULT_CITY = "Your City"

To customize microphone:
1. Find your mic: python -c "import speech_recognition as sr; print(sr.Microphone.list_microphone_indexes())"
2. Edit config.py:
   MIC_INDEX = 0  # Change to your mic index

================================================================================
🆘 TROUBLESHOOTING
================================================================================

Problem: "Python not found"
→ Solution: Add Python to PATH during installation, restart terminal

Problem: "ModuleNotFoundError"
→ Solution: Activate virtual environment, ensure (venv) shows in prompt

Problem: "Microphone not found"
→ Solution: Connect microphone, update MIC_INDEX in config.py

Problem: "Speech not recognized"
→ Solution: Speak clearly, increase SPEECH_TIMEOUT in config.py

For detailed troubleshooting:
→ See INSTALLATION.md "Troubleshooting" section (30+ solutions)
