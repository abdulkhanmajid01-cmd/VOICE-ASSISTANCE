## ⚙️ CUSTOMIZATION

Edit `config.py`:

### Add Wake Words
```python
WAKE_WORDS = ["jarvis", "assistant", "alice"]
```

### Change Theme
```python
GUI_THEME_COLOR = "#1a1a1a"  # Your color
GUI_ACCENT_COLOR = "#00FF00"  # Your color
```

### Adjust Microphone Sensitivity
```python
ENERGY_THRESHOLD = 1500  # Lower = more sensitive
```

## 🐛 TROUBLESHOOTING

### "No speech detected"
✓ Microphone working?
✓ Speaking loud enough?
✓ Quiet environment?

### Commands not executing
✓ Said wake word first?
✓ Spoke clearly?
✓ Internet connected?

### GUI not responding
✓ Close and restart
✓ Check microphone access
✓ Verify Python 3.8+
